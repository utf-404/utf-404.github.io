01

프로젝트 개요

문제

서로 다른 위치에서 촬영한 점군은 카메라 좌표계와 초기 자세가 달라 그대로 더하면 표면이 겹치지 않습니다. TF 오차와 센서 노이즈가 남으면 프레임 수가 늘수록 정합 오차도 누적됩니다.

접근

알려진 TF로 먼저 base_link 좌표계에 배치하고, 특징 기반 RANSAC으로 큰 자세 차이를 보정한 뒤 ICP와 포즈 그래프 최적화로 미세 오차와 누적 오차를 줄이는 단계형 파이프라인을 구성했습니다.

02

담당 범위

좌표 변환·전처리

  • TF JSON translation·quaternion을 4×4 변환행렬로 구성
  • Voxel downsampling과 surface normal 계산
  • FPFH 특징 생성과 빈 점군 입력 검증

정합·출력

  • RANSAC 초기 정합과 ICP 미세 보정
  • 인접 프레임 pose graph 및 전역 최적화
  • 이상점 제거, PLY 저장과 선택적 Poisson mesh 생성
03

처리 아키텍처

  1. LoadPCD · TF JSON
  2. PreprocessVoxel · Normal · FPFH
  3. CoarseFeature RANSAC
  4. RefineICP · Pose Graph
  5. ExportOutlier removal · PLY

TF만 적용하는 빠른 병합 경로와, TF가 충분하지 않을 때 RANSAC·ICP·전역 최적화를 사용하는 정합 경로를 분리했습니다.

04

핵심 구현

TF 기반 초기 배치

JSON의 translation과 x·y·z·w quaternion 순서를 Open3D의 w·x·y·z 순서로 변환해 회전행렬을 구성합니다. 모든 프레임을 base_link 기준으로 옮겨 초기 탐색 범위를 줄입니다.

특징 기반 초기 정합

다운샘플한 점군에서 normal과 FPFH를 계산하고 mutual filter, edge length와 거리 checker를 적용한 RANSAC으로 큰 위치·회전 차이를 먼저 보정합니다.

ICP 폴백

Point-to-plane ICP를 우선 사용하고 normal 계산 또는 최적화가 실패하면 Point-to-point 방식으로 폴백합니다. 한 방법의 예외로 전체 batch가 중단되지 않도록 했습니다.

전역 병합

인접 점군의 변환과 information matrix를 pose graph edge로 만들고 Levenberg–Marquardt 전역 최적화를 수행합니다. 병합 후 voxel downsampling과 통계적 이상점 제거를 적용합니다.

05

문제 해결

ICP 초기값 의존성

점군 간 차이가 크면 ICP가 잘못된 국소 최적점에 수렴할 수 있습니다. TF와 FPFH–RANSAC으로 초기 자세를 만든 뒤 ICP는 작은 오차 보정에만 사용했습니다.

Point-to-plane 전제 조건

Point-to-plane은 유효한 normal이 필요합니다. 점군별로 normal 존재 여부를 확인하고 없으면 재계산하며, 예외 발생 시 Point-to-point로 전환했습니다.

누적 오차

앞 프레임의 결과에 다음 변환만 계속 곱하면 오차가 누적됩니다. pair 정보를 pose graph로 구성해 전체 프레임의 자세를 한 번 더 최적화했습니다.

밀도와 처리 비용

원본 점군을 모든 단계에 사용하지 않고 특징 계산 전후에 voxel 크기를 다르게 적용했습니다. 마지막에는 이상점을 제거해 밀도와 결과 크기를 함께 관리했습니다.

06

검증 결과와 한계

각 정합 단계가 어떤 결과를 냈는지 확인할 수 있는 출력 경계를 만들었습니다.

인접 점군마다 fitness와 inlier RMSE를 출력하고, 폴더별 병합 PLY와 전체 병합 결과를 분리 저장합니다. 다만 저장소에는 동일 데이터의 TF-only 대비 정합 전후 수치와 대표 결과 이미지가 포함되어 있지 않아, 현재 포트폴리오에서는 알고리즘 구현 범위까지만 제시합니다.
