01

프로젝트 개요

문제

원물의 시작 위치가 달라지고 두께가 얇아 파지 오차와 충돌면 통과가 발생했습니다. 또한 로봇이 하류 이송이 끝날 때까지 기다리는 순차 구조에서는 컨베이어가 비어 있어도 다음 원물을 처리할 수 없었습니다.

접근

원물 쌍마다 독립 상태를 두고 로봇 동작과 하류 이송을 분리했습니다. 배치 이후에는 위치를 직접 변경하지 않고 동적 리지드 바디, Surface Velocity, 충돌과 마찰로만 이동하도록 구성했습니다.

04

핵심 구현

접촉 기반 컨베이어

투명 충돌면에 PhysX Surface Velocity를 적용했습니다. 해제된 10g 원물은 약 35mm를 실제로 낙하하고, 벨트와의 마찰로 이동하므로 충돌과 착지 조건을 함께 확인할 수 있습니다.

비동기 상태 파이프라인

각 원물 쌍을 small, WAITE, MEMORY, EGV 단계로 추적합니다. 특정 라인에 실제 착지한 것을 확인한 뒤 다음 벨트를 시작해 고정 시간만 기다리는 흐름을 줄였습니다.

재현 가능한 실행

--seed로 같은 시작 위치를 재현하고 --max-cycles와 --headless로 제한된 반복 검증을 실행합니다. 일시정지 중에는 물리와 단계 카운터를 함께 멈춰 재개 시 상태를 유지합니다.

성공 조건 판정

컨베이어 배치 오차, 실제 낙하 거리, 착지 후 수직 안정성, 최소 이동 거리와 최종 EGV 영역 도착을 코드에서 확인합니다. 허용 범위를 벗어나면 해당 사이클을 실패로 종료합니다.

05

문제 해결

얇은 원물의 충돌면 통과

12mm 높이 원물이 계단식 컨베이어 경계에서 터널링하는 현상을 확인했습니다. 동작 타이밍은 60Hz로 유지하되 물리 substep을 두 번 수행해 120Hz로 계산하고 실제 경계에는 충돌 스토퍼를 추가했습니다.

속도 단축 시 자세 오차

주요 동작을 기존 120프레임보다 빠르게 줄여 비교했습니다. 15프레임에서는 반복 중 허용 자세를 벗어났고, 문서화된 검증에서는 20프레임이 서로 다른 난수 조건 12사이클을 통과한 최소값이었습니다.

순차 처리의 유휴 시간

EGV 이송이 끝날 때까지 전체 루프가 막히던 구조를 원물 쌍별 job으로 분리했습니다. 로봇과 하류 이송을 동시에 진행하되 아직 완료되지 않은 쌍만 재사용을 기다립니다.

Pause 이후 상태 손실

타임라인이 멈춘 동안 렌더링만 유지하고 물리 step과 상태 카운터를 진행하지 않았습니다. 재생 시 중단한 단계부터 이어져 디버깅 중 상태가 건너뛰지 않습니다.

06

검증 결과와 한계

물리 정확도, 처리량과 재현성을 하나의 시나리오에서 비교했습니다.

문서화된 headless 검증에서 20프레임 조건은 서로 다른 난수 시드의 12사이클에서 파지와 배치 조건을 통과했고, 하류 이송과 다음 pick-and-place를 동시에 진행했습니다. 단, 이는 자동 생성된 테스트 리포트가 아닌 실행 기록이며 실제 ROS2 토픽은 아직 연결되지 않았습니다. 현재는 분리한 명령 경계를 테스트 이벤트가 대신합니다.
