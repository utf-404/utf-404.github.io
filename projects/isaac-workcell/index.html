01

프로젝트 개요

문제 정의

정형화된 박스를 기준으로 한 동일한 파지 조건만으로는 원형·중공 구조나 외형이 일정하지 않은 물체를 안정적으로 다루기 어렵습니다.

검증 목표

실제 설비를 구성하기 전에 물체별 충돌 형상, 강체 특성, 그리퍼 접촉과 로봇 이동 경로를 조정하며 작업 가능성을 검토했습니다.

02

담당 범위

작업 셀 구성

  • 로봇, 컨베이어, 그리퍼와 대상 물체 배치
  • STP·USD 기반 로봇 및 설비 자산 검토
  • 충돌 형상과 Rigid Body 속성 조정

동작 시나리오

  • 컨베이어 공급부터 Pick-and-Place까지 순서 구성
  • Action Graph와 standalone Python 상태 전이 구현
  • ROS2 제어 흐름 연결 및 반복 동작 점검
03

시뮬레이션 아키텍처

  1. Robot Assets로봇 · 그리퍼 · 컨베이어
  2. Physics Scene강체 · 충돌 · 접촉 조건
  3. State ControlAction Graph · Python
  4. Manipulation접근 · 파지 · 이송 · 배치
  5. ROS2 Flow제어 연결 · 상태 점검

물체 형상별로 Physics Scene의 충돌 범위와 접촉 조건을 조정하고, 동일한 상태 제어 흐름에서 동작을 비교하는 구조입니다.

04

핵심 구현

Tire

원형·중공 구조에서 접촉 지점과 파지 자세가 안정적으로 유지되는지 검토했습니다.

Food

종류와 취급 조건이 다른 식품을 대상으로 공급과 이송 공정 시나리오를 구성했습니다.

Irregular Object

외형이 일정하지 않은 대상의 충돌 범위와 파지 동작을 반복적으로 조정했습니다.

State Machine

대기, 접근, 파지, 이송과 배치 단계가 순서대로 전환되도록 동작 흐름을 구성했습니다.

05

문제 해결 관점

형상별 접촉 차이

대상 물체의 외형과 중심이 달라 동일한 그리퍼 설정을 그대로 적용하기 어려웠습니다. 물체별 충돌 형상과 접촉 조건을 분리해 조정했습니다.

동작과 물리 조건의 연결

상태 전이 순서만 맞아도 접촉과 강체 설정이 부정확하면 이송이 불안정해질 수 있어 동작 로직과 Physics 설정을 함께 검증했습니다.

06

결과와 다음 검증

한 가지 물체가 아닌 다양한 형상을 기준으로 작업 셀을 검토했습니다.

다음 단계에서는 형상별 반복 횟수, 파지 성공 기준, 실패 유형과 조정 전후 비교값을 추가해 시뮬레이션 결과를 수치로 보여줄 예정입니다.
